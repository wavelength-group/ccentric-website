# Ccentric website

Static HTML website for Ccentric Executive Search (a Wavelength Group company).

## How it works
- Plain HTML pages, no build step.
- Hosted on Netlify, connected to this repository.
- Every change committed here republishes the live site automatically.

## Structure
- `index.html` - homepage (copy of `ccentric-stacked-impact-final.html`)
- `ccentric-*.html` - individual site pages (industries, opportunities, resources, about, contact)
- `netlify.toml` - Netlify hosting configuration

## Editing
Day-to-day content editing is done through the CMS (to be added at `/admin`),
not by editing files directly. Design and template changes are handled via Claude.

## Ownership
Owned by the wavelength-group GitHub organisation.
